Jogo de pedra, papel e tesoura rodando sobre o framework Quarkus.


# Demonstração

Há uma gravação em vídeo, com narração em português.


# Executando

```shell script
./mvnw quarkus:dev
```


# Acessando pelo navegador

Abra no navegador:

```
http://localhost:8090/jankenpo/play?playerMove=PAPER
```

Troque o valor do parâmetro por uma destas opções:

- PAPER
- ROCK
- SCISSORS
